# Integration Checklist

Every integration should strictly follow this checklist to ensure consistency and quality.

## Before coding
- [ ] Read AI documents
- [ ] Read module README
- [ ] Locate Stitch screens
- [ ] Check shared components
- [ ] Check navigation

## After coding
- [ ] No duplicate widgets
- [ ] Uses design tokens
- [ ] Responsive
- [ ] No broken routes
- [ ] No console errors
- [ ] Module README updated
- [ ] Changelog updated
