# Design System

Everything generated from Stitch should follow this design system.

## Typography
Define the core font families, sizes, and weights to be used consistently across all components. Avoid custom font sizes outside of the defined tokens.

## Colors
Establish a consistent primary, secondary, background, text, and status (success, error, warning) color palette.

## Spacing
Use a standardized spacing scale (e.g., multiples of 4px or 8px) for margins and padding to ensure consistent layouts.

## Radius
Define border-radius tokens (e.g., small, medium, large, full) to maintain consistent curvature on interactive elements and containers.

## Shadows
Establish depth tokens (e.g., shadow-sm, shadow-md, shadow-lg) for elevations.

## Icons
Use a standard, unified icon library that aligns with the visual theme.

## Buttons
Standardize button styles for primary, secondary, ghost, and destructive variants, including their disabled, hover, and active states.

## Cards
Establish common card containers with consistent padding, borders, and shadow usage.

## Animations
Provide basic guidelines for micro-interactions and page transitions (e.g., ease-in-out, specific durations) to ensure a dynamic but smooth user experience.
