# Organiser Module

**Status**: Future Phase

## Purpose
The Organiser module allows club, academy, and event organisers to manage their organisations. This includes event creation, registration management, and overview of coaches and athletes within the organisation.

## Expected Scope
- Dashboard for organisation metrics.
- Event and tournament management.
- Academy roster and staff management.
- Messaging and broadcasting to members.

## Architecture Notes
- Role-based access control will be critical to ensure organisers only see their own data.
- UI elements will be sourced from Stitch.
