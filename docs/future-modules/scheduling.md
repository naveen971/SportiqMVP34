# Scheduling Module

**Status**: Future Phase

## Purpose
A shared utility module providing calendar, availability, and scheduling functionality across the platform (for practice, matches, events, and assessments).

## Expected Scope
- Calendar views (month, week, day).
- Conflict resolution.
- Reminders and notifications.

## Architecture Notes
- Will likely require a third-party calendar library or a complex custom implementation.
- Needs to be highly reusable across Coach, Organiser, and Athlete views.
